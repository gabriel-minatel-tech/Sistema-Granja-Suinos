## 📖 Sobre o projeto

Este projeto nasceu como um estudo aprofundado de três pilares da programação em C++:

- **Registros (`struct`)**: para modelar os dados de cada suíno da granja
- **Sub-rotinas (funções)**: para organizar e reaproveitar o código
- **Ponteiros**: para manipular dados diretamente na memória

Em vez de exercícios isolados, decidi juntar tudo em um problema do mundo real: **o controle de uma granja de suínos**.

## ✨ Funcionalidades

- ✅ Cadastro de suínos (identificação, raça, peso, idade, etc.) `[ajuste]`
- ✅ Listagem de todos os animais registrados
- ✅ Busca por identificação
- ✅ Edição e remoção de registros
- ✅ Relatórios simples (ex.: peso médio do rebanho) `[ajuste]`

## 🧠 Conceitos aplicados

| Conceito | Onde foi usado |
|---|---|
| `struct` | Registro com os dados de cada suíno |
| Sub-rotinas | Cada operação do menu tem sua própria função |
| Ponteiros | Passagem por referência e acesso aos registros `[ajuste]` |
